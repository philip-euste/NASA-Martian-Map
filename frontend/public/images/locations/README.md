# Location Imagery Assets

Place licensed NASA / JPL / USGS planetary photographs for each exploration site in this directory:

- `public/images/locations/jezero-crater/`
- `public/images/locations/gale-crater/`
- `public/images/locations/valles-marineris/`
- `public/images/locations/olympus-mons/`

Then register the file path, caption, and credit in `src/data/explorationSites.ts` under the site's `images` array.
